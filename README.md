# 数学基础作业

本仓库包含三份作业，均以 Markdown + LaTeX 公式编写：

| 文件 | 主题 |
|---|---|
| [01-svd.md](01-svd.md) | 奇异值分解（SVD）的原理、分解过程与手算实例 |
| [02-bayesian-ctr.md](02-bayesian-ctr.md) | 贝叶斯推断过程与推荐系统点击率估计的数学建模 |
| [03-cross-entropy.md](03-cross-entropy.md) | 交叉熵的定义、原理、推导与应用 |

## 作业要求对应

1. **奇异值分解**：给出 SVD 定理、完整分解步骤（五步推导），并对手选矩阵 $A\in\mathbb{R}^{3\times2}$ 逐步手算验证，最后给出截断 SVD 的最优低秩逼近。
2. **贝叶斯过程**：以「推荐系统广告位点击率估计」为项目背景，完整建模（伯努利似然 + Beta 先验 → Beta 后验），含后验推导、点估计、可信区间、序贯更新与 A/B 物品对比。
3. **交叉熵**：从信息熵、KL 散度出发推导交叉熵，给出三分类数值算例，推导 softmax + 交叉熵的梯度，并给出二分类交叉熵的等价形式。
4. 全部内容以 Markdown 格式提交至 Git 仓库。
